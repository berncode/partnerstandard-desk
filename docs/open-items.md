# Open items

What is planned next, in no fixed order. Each one starts with a design, agreed in an issue before any code.

- **A team view:** how every partner manager's partners are doing, on one page.
- **CRM connectors:** link a partner to its record in your CRM. A connector changes data only through the commands layer, like everything else.
- **The levels review:** check real partners against a program level's requirements, with a yearly list of who moves up or down.
- **An exit plan:** close a partnership step by step, with both sides in view.
- **Postgres** as a second database for a company's own server, next to SQLite.

Have an idea or found a bug? Open an issue.
